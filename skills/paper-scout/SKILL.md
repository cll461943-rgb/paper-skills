# paper-scout：文献检索、建库、精读与查新

本技能负责论文研究前期的证据摸底，对应阶段门 G1（文献）以及 G2（创新点）中的专项查新环节。它把零散的检索结果收束成可追溯的 `paper_matrix.csv`、结构化精读卡片和可审计的查新报告，为后续找空白与定方向提供事实底座。

## 何时使用 / 不适用

适用情形如下。

- 刚确定研究方向，需要系统摸清该方向的主要路线、代表作、开源基准和瓶颈。
- 已有零散论文清单，但来源单一、字段不齐或缺少正式发表版本核验，需要补抓与去重。
- 准备对核心论文建立统一格式的精读卡片，提取方法假设、实验边界和可复用原语。
- 候选创新点初步成形，需要执行专项查新以确认是否撞车。

不适用情形如下。

- 尚未有基本研究方向或问题域（应先通过 `paper-pilot` 完成 G0 选题界定）。
- 只需要对单篇论文做中英全文翻译或润色改写（不在此技能范围）。
- 已经进入成文阶段，只想按格式核对参考文献条目（应交由 `paper-format` 处理）。
- 希望 AI 直接替作者拍板最终研究问题（作者始终是作者，本技能只输出证据与空白清单）。

## 输入

启动本技能前，需要尽量明确以下输入。缺少次要项可以先按保守默认启动，但检索范围和时间边界必须在产出中写明。

1. 研究主题与核心问题域（中英文关键词、同义词及常见缩写）。
2. 目标期刊或会议类型（用于判断哪些奠基论文和近期顶会必须覆盖）。
3. 已有种子论文列表或本地文献目录（可选，用于滚雪球引文检索与本地索引对齐）。
4. 查新模式下的候选创新点一句话描述及核心机制关键词（仅查新时需要）。
5. 截止日期与时间窗口要求（默认覆盖经典奠基工作、近三年主力文献以及最近 3 个月预印本）。

## 流程

按以下六个步骤顺序推进，每一步结束时核对可检查产出。

### 步骤 1：界定检索范围与多源策略

把主题拆成核心概念组与扩展同义词，分别列出至少四个渠道的检索计划：arXiv、Semantic Scholar、OpenAlex 和本地已有索引（含个人文献库或项目已有下载目录）。记录每个渠道的查询语句、时间窗与单次上限。若某渠道触发限流，保留已抓取分页的断点并改用其余渠道补齐，避免单一渠道中断拖垮全库。

可检查产出：一份 `search_log.md`，包含各来源的检索式、执行日期、时间范围、命中数以及限流或补抓记录。

### 步骤 2：多源抓取、清洗与去重

汇总各渠道元数据，按三级键做去重：优先比对规范化 DOI，其次比对去版本号的 arXiv ID，最后比对去除标点与大小写后的标题加第一作者姓氏及年份。同一篇论文若同时存在预印本与正式发表版本，必须合并为一条记录，以正式发表版本为主条并保留 arXiv ID 供追溯。标记明显跑题或缺乏实验支撑的条目，保留筛选原因而非静默删除。

可检查产出：去重统计简报（原始命中数、去重数、初筛保留数、冲突合并数）。

### 步骤 3：构建论文矩阵 `paper_matrix.csv`

把筛选后的文献写入 `paper_matrix.csv`。矩阵必须支持后续按"问题瓶颈、技术原语、评测基准"做切片统计，核心字段包括以下内容。

| 字段名 | 用途说明 | 填写规范 |
|---|---|---|
| `paper_id` | 唯一短标识 | 建议 `arXivID` 或 `AuthorYear_Keyword` |
| `title` / `authors` / `year` | 基础书目信息 | 统一英文原文或规范译名 |
| `venue` / `pub_status` | 发表去向与状态 | 区分 `published`、`preprint`、`workshop` |
| `doi_or_arxiv` | 可核验标识 | 正式发表补 DOI，预印本留版本号 |
| `problem_tag` | 针对的核心痛点 | 与项目瓶颈词表对齐 |
| `method_primitive` | 核心技术原语 | 一句话概括机制，不抄营销口号 |
| `benchmark_dataset` | 评测数据集与环境 | 写清真实系统还是合成基准 |
| `key_assumption` | 隐含前提或边界 | 如是否依赖离线 Oracle、已知故障集 |
| `relevance_tier` | 精读优先级 | `A`（核心必读）、`B`（对照参考）、`C`（背景） |
| `card_path` | 精读卡片路径 | 已精读填相对路径，未读填 `待补` |

可检查产出：结构完整、无重复键、发表状态核验完毕的 `paper_matrix.csv`。

### 步骤 4：分层精读并产出卡片

对 `relevance_tier` 为 `A` 的核心论文逐篇精读，按 [references/card_template.md](references/card_template.md) 生成卡片存入 `cards/` 目录。动笔前先判定材料边界：能看到完整正文与图表的标为全文级，只有纯文本缺图表的标为文本级，仅拿得到摘要和元数据的标为摘要级。卡片里严格区分作者原话与分析判断，缺少原文支撑的栏目统一写明无法从现有材料评估，绝不脑补实验数字或页码。

可检查产出：`cards/` 下的系列精读卡片，且 `paper_matrix.csv` 中的 `card_path` 全部回填。

### 步骤 5：提炼领域现状与瓶颈清单

综合论文矩阵与核心精读卡片，输出一页纸的现状综述，正面回答两个问题：现有工作已经稳固做到哪里，关键缺口卡在什么地方。每条瓶颈必须绑定至少两篇精读卡片中的具体证据（如失败案例、前提限制或消融暴露的短板），同时列出该方向绕不开的经典奠基工作清单，防止后续写相关工作时只剩近一年预印本。

可检查产出：`bottlenecks.md`（瓶颈清单）与经典奠基文献子表。

### 步骤 6：专项查新（含最近 3 个月预印本强制扫描）

在候选创新点送审或立项前，按 [references/novelty_check.md](references/novelty_check.md) 执行专项查新。除常规检索外，必须对 arXiv、Semantic Scholar 和 OpenAlex 做一次最近 3 个月的预印本定向扫描，防止热门方向的同期工作撞车。将最接近的论文按"完全撞车、局部重叠、互补前置"分级对照，写清本方案与每篇近似工作的精确边界。

可检查产出：针对每个候选方向的专项查新报告（`novelty_<topic>.md`）。

## 检查清单

进入下一阶段前，逐条核对以下项目。

- [ ] 至少使用了两个外部检索源并结合本地索引，不存在单源限流漏抓未补齐的情况。
- [ ] `paper_matrix.csv` 已完成 DOI、arXiv ID 与标题三级去重，预印本已核查是否已有正式发表版本。
- [ ] 矩阵中同时覆盖了领域经典奠基工作和近三年主力论文，没有清一色堆砌当年预印本。
- [ ] 所有 `A` 类核心论文均有独立精读卡片，每张卡片都写明了材料边界与证据定位（节、图、表或页码）。
- [ ] 卡片中没有把某篇论文 Related Work 的二手评价直接当成已验证的领域共识。
- [ ] 专项查新已完整执行最近 3 个月预印本扫描，并给出具体的检索日期与检索式。
- [ ] 能够基于矩阵与卡片写出有证据指向的"现有工作做到哪里、缺什么"。

## 常见失败

以下问题均来自真实项目实践，执行时需重点防范。

1. 依赖单一渠道导致限流与时间断层。在一次 LLM agent 记忆审计项目的文献摸底中，检索脚本重度依赖 arXiv 接口并触发限流，同时本地索引仅覆盖到较早年份，导致近一年多篇关键预印本漏检，直到查新阶段才被迫返工补抓。规避办法是固定采用多源检索，并在 `search_log.md` 中显式记录各源的时间边界与断点增量补抓记录。
2. 只查正式发表会议录而跳过最近 3 个月预印本。快速演进的 AI 子领域里，真正构成撞车风险的工作往往在近 90 天内刚挂上 arXiv。只看去年顶会论文集会造成虚假空白感，等实验跑到中期才发现核心机制已被抢发。规避办法是把近 3 个月预印本扫描设为查新硬门，缺此项不通过 G2。
3. 仅凭摘要写卡片，遗漏方法的隐含前提。许多论文在摘要里声称解决了通用问题，但正文实验却依赖已知故障源（Oracle）或人为简化的状态日志。只读摘要会把这些工作误标为已完全解决该瓶颈，或误判为公平基线。规避办法是核心论文必须核对正文方法假设与实验设置，并在卡片中单独列出隐含前提。
4. 参考文献过度偏向当年预印本，忽略正式发表版与奠基文献。某项目初稿的 62 条参考文献几乎全是同年的 arXiv 预印本，既漏掉了已正式录用的会议版本，又缺少该方向公认的经典工作，被审稿人直接质疑学术根基不牢。规避办法是在建库阶段就记录 `pub_status` 并补齐经典基线与正式出处。

## 与其他技能的衔接

- 上游来源：`paper-pilot` 完成 G0 选题界定后，将研究方向、目标去向与时间线交接给本技能。
- 下游去向：本技能产出的 `paper_matrix.csv`、精读卡片和 `bottlenecks.md` 直接喂给 `paper-idea`，用于构建"瓶颈 × 方法"交叉矩阵。
- 双向协同：`paper-idea` 产生候选方案后，需再次调用本技能的步骤 6 出具专项查新报告，通过后才算满足 G2 退出条件。
- 后期复用：整理好的正式发表信息与经典文献清单会在 `paper-story`（相关工作骨架）和 `paper-format`（参考文献逐条核验）阶段直接复用。
