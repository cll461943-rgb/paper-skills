# paper-figure：图清单设计、制图规范与看图验收

一张图只传递一句话。读者翻开论文前两页时，往往先扫图再读字。如果图表信息杂乱、配色漂移或与正文打架，整篇稿件的可信度会立刻打折。本技能负责阶段门 G5，将论证骨架和冻结实验数据转化为结构紧凑、视觉统一、经得起审稿人放大审视的整套论文图表。

## 何时使用 / 不适用

适用场景：
- 已通过阶段门 G4，手里有作者确认的论证骨架 `outline.md` 和贡献-证据对照表，准备规划整篇论文的图清单。
- 需要把抽象方法说明改成具体实例驱动的图 1（teaser），或重画带局部机制透视的架构图。
- 需要为全篇数据图锁定色盲友好配色、字体字号、栏宽尺寸和可复现的 `matplotlib` 绘图脚本。
- 需要对已有成图做脱离正文的看图验收，或在审稿返修阶段按意见重绘问题图。

不适用场景：
- 实验结论尚未冻结，仍处于探索性数据分析或调参排查阶段，此时应先回 `paper-evidence` 跑通数据。
- 尚未确定论文核心主张与各节目的，此时画图很容易画出与正文脱节的空框，应先完成 `paper-story`。
- 只需要把现成矢量图排版进 LaTeX 模板或处理浮动体跨页位置，这类版面工作交给 `paper-format`。
- 需要交互式网页看板或业务汇报 PPT，本技能面向静态印刷与 PDF 审阅的学术图表。

## 输入

进入本技能前需要备齐以下材料：
1. 论证骨架 `outline.md` 与贡献-证据对照表（来自 `paper-story`），用于确定每张图支撑哪一条主张。
2. 冻结后的实验结果文件（CSV 或 JSON）及统计区间（Wilson 置信区间、配对 bootstrap 区间、样本量 $n$），来自 `paper-evidence`。
3. 目标期刊或会议的栏宽规格、总图表预算和图注字数要求（来自 `paper-format` 的 `references/venues.md`）。
4. 若为返修重绘，另需提供元审稿中的逐图修改意见（来自 `paper-review`）。

## 流程

按以下六个步骤推进，每一步都有明确的检查产出。

### 1. 制定全篇图清单 `figure_plan.md`

动手画任何一张图之前，先在 `figure_plan.md` 中列出整篇论文计划保留的主图与附录图。主文图表一般收敛在 5 至 7 张高密度图，避免用整张图去展示三四根柱子。每张图必须登记六项信息：图号、一句话核心信息、支撑的贡献或研究问题编号、图表类型（实例图 / 架构图 / 数据图）、栏宽占用（单栏或双栏），以及这张图替代或合并了哪张冗余表格。

产出：`figure_plan.md`。检查标准是删掉所有装饰词后，每张图只剩一句可验证的科学陈述，且与正文表格不重复汇报同一组数字。

### 2. 设计具体实例 Teaser 与机制架构图

第一张图必须从真实案例出发，让读者十秒内看懂问题为什么发生、现有方法为何漏检、本文方案如何介入。严禁用抽象概念方框加双向箭头充当图 1。例如在长期记忆审计场景中，应按时间轴画出“写入旧值、用户更正新值、旧值仍处活跃状态、检索命中旧值”的完整链路，再对照两路证据各自看到什么。

方法架构图不能退化成文字塞满的方框流水线。画图前先拆清输入通道、核心模块和输出边界，只在主图里画已经实现并完成实验验证的路径。未实现的设想方案一律不进主图，也不能靠角落一行小字灰注来免责。模块内部应给出微型机制透视（例如一小块来源子图或状态转移示意），让图本身承担解释原理的作用。

若采用图像生成模型制作架构图或概念图初稿，先读取 [references/architecture_prompt.md](references/architecture_prompt.md)，严格遵循扁平矢量、柔和浅色、纯白背景、文字仅作短标签的原则生成参考底稿，再转入矢量工具修正文字、对齐符号并输出可编辑矢量文件。定量数据图禁止交给图像生成模型绘制。

产出：图 1 与架构图的定稿矢量文件（PDF 或 SVG）及文字标签核对表。

### 3. 锁定全篇数据图风格系统

绘制第一张数据图之前，先读取 [references/plot_style.md](references/plot_style.md)，在项目中落盘一份共享样式模块（如 `plot_style.py`）和一张“全篇色义锁定表”。

色义锁定表规定每种颜色在整篇论文中只能绑定一个固定对象（如最终方法、语义基线、结构基线）。换到另一张图讲不同维度的分组或曝光条件时，改用点形、线型、填充纹理或灰阶，绝不挪用已绑定的方法色。统一无衬线字体、字号阶梯、单双栏物理宽高、线宽和子图面板标号格式，保证七张图并排放在桌面上像出自同一套出版系统。

产出：共享样式脚本 `plot_style.py` 与色义锁定表。

### 4. 编写数据驱动的绘图脚本

所有数据图由单一脚本从冻结结果文件直接读取生成，禁止手动抄写数字，禁止引用已弃用的中间原型结果。绘图时把统计严谨性直接编入视觉元素：
- 样本量悬殊或总数较小的分组（如几十例以内），必须直标分子分母或 $n$ 值，并附置信区间误差棒。
- 避免截断坐标轴的双 Y 轴叠图；量纲不同的指标拆分成共享横轴的上下子图，或把次要面板移入附录。
- 若分组随横轴变化导致样本成员漂移，禁止用折线跨组连接，改用分组点图加区间，或在受控配对条件下再连线。
- 森林图或差值对比图必须画清零参考线、标明有利方向与配对统计单位，避免无误差棒的孤点悬空。

产出：可一键复现全部数据图的脚本及原始输出目录。

### 5. 矢量导出与物理尺寸预检

数据图与架构图统一导出嵌入字体的矢量格式（PDF 与 SVG），辅以 600 DPI PNG 便于快速审阅。导出时按目标期刊的实际物理栏宽（单栏约 3.3 至 3.5 英寸，双栏约 6.8 至 7.1 英寸）直接设定画布尺寸，不在 LaTeX 中靠暴力缩放把大画布缩进窄栏。

多面板图导出前检查同行或同列子图的绘图区域边界对齐、间距一致以及文字无遮挡、无截断。将导出的 PDF 缩放到实际印刷大小（100% 视图）和灰度预览各看一遍，确认最小刻度字号依然清晰，色盲或黑白打印下各曲线与柱组仍可分辨。

产出：印刷尺寸达标的全套矢量图文件。

### 6. 独立看图验收与图文一致性对齐

全部图生成后，读取 [references/figure_review.md](references/figure_review.md) 逐图过检。验收时先盖住正文，只看图和图注，测试能否在十秒内准确复述 `figure_plan.md` 写下的那句话。随后逐项比对正文、图注、算法伪代码与图内标签，确保数学符号、方法正式名称、指标个数和数据集名称完全一致。所有阻断项修复完毕后，在 `status.md` 登记通过阶段门 G5。

产出：逐图验收记录，确认 G5 退出条件全部满足。

## 检查清单

- [ ] `figure_plan.md` 中每张图都有明确的一句话信息，且对应到具体贡献或研究问题。
- [ ] 图 1 是具体运行实例，而非抽象概念方框图。
- [ ] 架构图只画已实现和已验证的路径，并包含关键机制的局部视觉示意。
- [ ] 全篇共用同一套色盲友好调色板与色义锁定表，不存在一色多义。
- [ ] 所有数据图均使用最终版方法的冻结结果绘制，无已弃用原型残留。
- [ ] 小样本与比例类结果均标注了 $n$ 或分母及置信区间，无截断双 Y 轴，无误导性跨组连线。
- [ ] 图内数学符号、方法名、指标项与正文及图注 100% 一致，无漏括号或拼写瑕疵。
- [ ] 所有图已按实际栏宽矢量导出，100% 物理尺寸与灰度模式下均清晰无碰撞。

## 常见失败

以下反例均来自真实初稿（v0.1 七张图）被多方审稿人一致打回的教训，画图与验收时须逐条避坑：

1. 图 1 退化成方向混乱的概念框且无具体实例。案例中，原图 1 把审计器放在正中，箭头同时向左指故障类别、向右指混合框架，虚线混排任务指标与派生口径，右侧文字写成串行确认却与正文并行打分冲突，还塞进了尚未实现的 I2 至 I4。改法是换成单次用户更正的时间轴实例图，直接对照两路证据的可见范围。
2. 架构图用代码硬画六个纯文字方框，且符号打架。案例中，原图 2 用 `matplotlib` 拼出矩形流程图，没有任何来源子图或概率更新的视觉机制；框内把生命周期先验写成 $p_{\mathrm{life}}$，与正文和算法伪代码里的 $p_{\text{struct}}$ 冲突；框底还印着未验证的灰字说明，右侧挂着正文已证明无净增益的剥离模块。改法是重绘带微型子图透视的矢量架构图，只保留落地路径并锁死符号表。
3. 低信息密度条形图与正文表格重复，且缺误差棒。案例中，原图 3 占满单栏却只画 4 根柱子，数据与表 4 完全重合；子类样本量只有 14、29、37 却没有 Wilson 置信区间，深色总计柱又容易被误读成第四个并列子类。改法是删去冗余表格，把存储残留、日志构成与检索暴露合并为高密度多子图。
4. 选择偏差下的跨组折线制造因果倒置错觉。案例中，原图 4 把“过期记忆在视野内”与“不在视野内”的准确率按 $k$ 连成折线，结果在 $k=3,5$ 处前者高达 90% 至 92%，稳稳压在后者 77% 至 79% 之上。即便图底加了小号灰字提示选择偏差，快速扫图的审稿人依然会产生“过期记忆反而提升效果”的误读。改法是按同会话配对干预或按新旧同时召回条件重新分层，不在成员漂移的组间拉折线。
5. 截断双 Y 轴叠加不同量纲，且前后图单位不统一。案例中，原图 5(b) 左轴画答对会话数（of 54），右轴叠放截断在 87% 至 100% 的存储残留率，同时与图 4 的百分比纵轴量纲打架。改法是拆掉双 Y 轴，统一成百分比坐标，并把仅含 3 根柱子的子图 (a) 直接并入横轴标注。
6. 主结果图错画已弃用原型，且图文指标不符。案例中，原图 6 展示核心互补性却画了已经承认过拟合并弃用的原型 `ours_v2`，第四组横轴还漏掉括号把 `(n=5)` 写成 `n=5`，把仅 5 例的类别与 50 例的类别等宽并排；原图 7 图注宣称展示四项指标，实际画布只画了两项，还留着无误差棒的孤点。改法是主图严格绑定最终版冻结数据，每张图交付前把图注和代码逐项对表。
7. 全篇色义漂移。案例中，蓝色在不同图里先后编码语义方法、某个 $k$ 值以及新旧条目同时可见，橙黄色同时代表证据类别、状态和方法。改法是建立并强制执行全篇色义锁定表。

## 与其他技能的衔接

- 上游：`paper-story`（提供 G4 确认的论证骨架与贡献-证据表）和 `paper-evidence`（提供冻结数据与置信区间）。
- 横向：`paper-format`（提前确认目标期刊的栏宽、图表总数限制和图注字数规则）。
- 下游：`paper-write`（正文按 `figure_plan.md` 引用图表、撰写精准图注并删去重复表格）与 `paper-review`（G7 阶段按原图与排版 PDF 审图，发现致命图缺陷时回退到本技能重绘）。
