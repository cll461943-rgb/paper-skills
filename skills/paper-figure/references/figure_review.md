# 看图验收清单与反例对照表

本清单用于阶段门 G5 放行前及返修重绘后的独立视觉验收。验收原则是“先脱离正文看图，再对照正文核表”。

## 一、十秒独立看图测试

盖住正文，只看图文件与下方图注，回答三个问题：
1. 这张图要我记住的唯一结论是什么？如果超过十秒仍看不出主次，说明信息过载或缺少视觉焦点。
2. 图里的每个元素（坐标轴、颜色、线型、箭头方向、误差棒）是否都能在图和图注里找到解释？如果需要翻三页正文才懂缩写，图注不合格。
3. 这张图是不是在重复某张正文表格的数字？如果是，删表留图，或者把低密度小图并入多子图。

## 二、五维逐项验收清单

### 1. 信息与叙事
- [ ] 图 1 呈现的是具体运行案例，而非抽象概念盒子。
- [ ] 每张图的视觉焦点准确落在要证明的核心差异上，不存在喧宾夺主的无关曲线或背景色块。
- [ ] 图注先用一句话点明核心结论或图内容（避免冗余的 “The figure shows...”），再说明面板含义、误差棒定义和样本范围。

### 2. 科学诚实与统计规范
- [ ] 主结果图展示的是最终定版方法，没有混入已声明弃用的旧原型。
- [ ] 所有比例、均值或分组对比均标出样本量 $n$（或分子分母）以及置信区间/标准误（单次确定性统计须注明口径）。
- [ ] 坐标轴起点合理；不通过截断双 Y 轴制造相关性错觉；同类对比面板共享同一量纲与刻度范围。
- [ ] 折线仅用于连接同一组样本在连续变量下的演变；若随横轴变化样本集合发生改变，改用分组点图或重新做配对分层。

### 3. 机制与图文一致性
- [ ] 架构图中画出的每一条分支、规则和模块均已在正文实现并验证；未完成项绝不入主图。
- [ ] 图内数学符号、方法正式名称、指标缩写与正文、公式、算法伪代码完全一致。
- [ ] 图注声称包含的面板数和指标数与画面实际绘制的内容逐项对应（例如图注写四项指标，图里不能只画两项）。
- [ ] 图内语言与投稿目标语言统一（英文投稿全英文；若为中文内部稿，图内与正文编码符号须在图注映射清楚）。

### 4. 视觉系统与排版细节
- [ ] 全篇色义严格遵守色义锁定表，同一种颜色未在不同图里兼任两种语义。
- [ ] 所有图的字体家族、字号阶梯、边框粗细、子图标号 `(a)/(b)` 位置风格统一。
- [ ] 多面板图对齐工整，图例不压住数据点或误差棒，坐标标签不拥挤、无漏括号或拼写错误。
- [ ] 缩放到目标期刊实际栏宽（100% 视图）检查，最小字号清晰可辨；转灰度预览后主要组别仍能靠形状、线型或深浅区分。
