# 投稿前格式与合规检查清单

在阶段门 G6 交付审稿前及阶段门 G8 正式投稿前，逐项核验本清单。发现任何标为【阻断】的项目未通过，必须先修复再输出 PDF。

## 1. 模板、篇幅与必需组件
- [ ] 【阻断】已使用目标期刊或会议当年官方最新模板，未擅自篡改页边距、字号、行距或段落间距。
- [ ] 【阻断】正文页数严格符合目标上限，摘要字数在规定范围内，不超行不越界。
- [ ] 【阻断】目标去向要求的附加组件已齐备且合乎字数规则：
  - Elsevier：3–5 条纯英文 Highlights（每条 ≤85 字符含空格）、CRediT 声明、利益冲突声明、数据可用性声明。
  - IEEE：无引用的独立摘要、Index Terms。
  - NeurIPS / ICML / ICLR：Paper Checklist / Impact Statement / Ethics 或 Reproducibility 声明。
  - ACL ARR：强制 Limitations 专节与 Responsible NLP Checklist。
- [ ] 全稿体例单一，没有把另一出版体系的模块（如把 Elsevier 声明混入会议模板）误留稿中。

## 2. 占位符与工程痕迹清零
- [ ] 【阻断】全局检索 `TODO`、`TBD`、`FIXME`、`RED`、`待补`、`待核`、`占位`、`XXX`、`???`，结果全部为零。
- [ ] 【阻断】正文、图注、表头与附录中无实验室周次号、旧原型代码名、脚本变量名、私有哈希盐或调试报错文件名。
- [ ] 所有表格单元格无无故留空；解释性说明均已归入表注或图注，而非塞进单元格或夹带红字。

## 3. 匿名与隐私脱敏（双盲投稿必查）
- [ ] 【阻断】关闭模板终稿开关（打开匿名审查模式），首页无作者姓名、单位、邮箱、致谢与基金项目号。
- [ ] 【阻断】正文引用作者团队过往工作均已改为客观第三人称表述，未泄露“我们此前提出”。
- [ ] 【阻断】代码与数据链接已替换为匿名访问地址或打包为匿名补充材料，未暴露个人/机构仓库名。
- [ ] 【阻断】已清理 PDF 文件属性元数据（Author、Title、Subject、Creator 中的个人信息），且正文及附录无本地磁盘路径或可定位仓库的私有 commit 哈希。

## 4. 公式、算法、表格与浮动体（须逐页目视 PDF）
- [ ] 【阻断】所有展示公式编号与公式主体同行右对齐，无编号掉行到左侧的现象；所有数学符号定义清晰且全篇一致。
- [ ] 算法伪代码位于单页内可读，无从输入输出处硬断页，无长变量名冲出栏宽。
- [ ] 所有表格采用 `booktabs` 三线样式（无竖线），无表题留在页末而表体掉入下一页的情况；跨页长表已自动重复表头。
- [ ] 检查编译日志，无明显超出页边距的 `Overfull \hbox`（一般容忍度小于 10 pt 且目视不越界）。
- [ ] 无孤立章节标题挂在页尾，无图表堆积在文末或与首次正文引用相隔多页，无整半页异常空白。

## 5. 图表清晰度与语言统一
- [ ] 【阻断】全部插图为高质量矢量格式（PDF/SVG）或满足印刷分辨率要求，无马赛克、锯齿或失真拉伸。
- [ ] 缩放到 100% 实际印刷尺寸检查，所有图内标签、坐标刻度与图例字号清晰可读，无文字重叠或被裁切。
- [ ] 图内文字语言与正文投稿语言一致，图注与图内实际面板和指标一一对应。

## 6. 参考文献与文件打包
- [ ] 【阻断】所有参考文献由单一 `refs.bib` 自动生成，章节末尾无残留的局部引用清单。
- [ ] 【阻断】编译日志无 `Undefined citation`、无正文里的 `[?]` 问号、无重复文献条目。
- [ ] 核查全部 arXiv 预印本条目：凡已在顶会或期刊正式发表的均已替换为正式出版信息；字段完整无缺作者缺年份。
- [ ] 生成的 PDF 已嵌入全部字体，中文/英文正文均可正常选中复制与检索，无乱码字符。
- [ ] 若为返修提交，同时备齐：干净修订稿 PDF、高亮改动对比版（`latexdiff` 或按要求标色）、逐条回复信 PDF。
