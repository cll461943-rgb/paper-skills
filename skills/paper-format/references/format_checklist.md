# 投稿前格式与合规检查清单

在阶段门 G6 交付审稿前及阶段门 G8 正式投稿前，逐项核验本清单。发现任何标为【阻断】的项目未通过，必须先修复再输出 PDF。

## 1. 模板、篇幅与必需组件
- [ ] 【阻断】已对照项目格式卡登记的官方指南版本与核对日期，使用目标期刊或会议当届官方最新模板（如 ACL ARR 完整 `acl_latex` 发布包而非拼凑的旧 `acl.sty`），未擅自篡改页边距、字号、行距或段落间距。
- [ ] 【阻断】当前阶段（初投、答辩、返修或终稿）的正文页数严格符合格式卡核验的当届上限，参考文献、附录、Checklist、Impact、Limitations 与 Ethics 的计页口径无误，摘要字数在规定范围内，不超行不越界。
- [ ] 【阻断】目标去向要求的附加组件、声明与平台问卷已按适用性和上传位置备齐：
  - Elsevier（按 Information Fusion / KBS 分刊核验结果执行）：若目标刊物要求提交 Highlights，已按独立可编辑文件准备并核验为 3–5 条纯英文要点、每条不超过 85 个字符（含空格）；CRediT 贡献声明、利益冲突声明与数据可用性声明已按该刊物要求的适用性和上传位置（稿件文末、独立文件或系统表单）填妥。
  - IEEE：无引用、无复杂公式的独立摘要，以及规范的 Index Terms。
  - NeurIPS / ICML / ICLR：NeurIPS Paper Checklist、ICML 采用当届模板规定标题的影响声明（如 `Impact Statement`）、ICLR 按当届要求准备的 Ethics / Reproducibility 声明均已就位。
  - ACL ARR：稿件内必填 `Limitations` 专节（及按需 `Ethics Statement`）已就位，投稿系统内的 Responsible NLP Checklist 等问卷已单独核对并准备填报。
- [ ] 【阻断】已按目标去向当届政策检查 AI / LLM 使用披露要求（G8 必查），需要披露时已在指定位置如实说明。
- [ ] 全稿体例单一，没有把另一出版体系的模块（如把 Elsevier 声明混入会议模板）误留稿中。

## 2. 占位符与工程痕迹清零
- [ ] 【阻断】全局检索 `TODO`、`TBD`、`FIXME`、`RED`、`待补`、`待核`、`占位`、`XXX`、`???`，结果全部为零。
- [ ] 【阻断】正文、图注、表头与附录中无实验室周次号、旧原型代码名、脚本变量名、私有哈希盐或调试报错文件名。
- [ ] 所有表格单元格无无故留空；解释性说明均已归入表注或图注，而非塞进单元格或夹带红字。

## 3. 匿名与隐私脱敏（按目标盲审政策核查）
- [ ] 【阻断】已对照格式卡确认盲审类型与预印本/匿名期政策；双盲投稿时已关闭模板终稿开关（开启匿名审查模式），首页及正文中无作者姓名、单位、邮箱、致谢与基金项目号。
- [ ] 【阻断】正文引用作者团队过往工作均已改为客观第三人称表述，未泄露“我们此前提出”等归属暗示。
- [ ] 【阻断】代码与数据链接符合当届匿名链接规则，已替换为匿名访问地址或打包为匿名补充材料，未暴露个人/机构仓库名、用户名或 `.git` 提交历史。
- [ ] 【阻断】已清理主稿 PDF 及补充材料的文件属性元数据（Author、Title、Subject、Creator 中的个人信息），且正文、附录与复现说明中无本地磁盘路径或可定位私有仓库的 commit 哈希。

## 4. 公式、算法、表格与浮动体（须逐页目视 PDF）
- [ ] 【阻断】所有展示公式遵守目标模板规定的编号位置，编号与公式主体无重叠、无越界、无异常掉行，且正文中全部公式交叉引用正常解析；数学符号定义清晰且与 `glossary_and_symbols.md` 全篇一致。
- [ ] 算法伪代码位于单页内可读，无从输入输出处硬断页，无长变量名冲出栏宽。
- [ ] 所有表格采用 `booktabs` 三线样式（无竖线），无表题留在页末而表体掉入下一页的情况；跨页长表处理合规（仅在允许单栏或单栏附录时使用 `longtable` 自动重复表头，双栏模式下已拆表并手动重复表头，或按规定移入补充材料）。
- [ ] 检查编译日志，无明显超出页边距的 `Overfull \hbox`（一般容忍度小于 10 pt 且目视不越界）。
- [ ] 无孤立章节标题挂在页尾，无图表堆积在文末或与首次正文引用相隔多页，无整半页异常空白。

## 5. 图表清晰度与语言统一
- [ ] 【阻断】全部插图为高质量矢量格式（PDF/SVG）或满足印刷分辨率要求，无马赛克、锯齿或失真拉伸。
- [ ] 缩放到 100% 实际印刷尺寸检查，所有图内标签、坐标刻度与图例字号清晰可读，无文字重叠或被裁切。
- [ ] 图内文字语言与正文投稿语言一致，图注与图内实际面板和指标一一对应。

## 6. 参考文献、复现材料与分阶段打包
- [ ] 【阻断】所有参考文献由单一 `refs.bib` 自动生成，章节末尾无残留的局部引用清单。
- [ ] 【阻断】编译日志无 `Undefined citation`、无正文里的 `[?]` 问号、无重复文献条目。
- [ ] 核查全部 arXiv 预印本条目：凡已在顶会或期刊正式发表的均已替换为正式出版信息；字段完整无缺作者缺年份。
- [ ] 生成的 PDF 已嵌入全部字体，中文/英文正文均可正常选中复制与检索，无乱码字符。
- [ ] 【阻断】G8 正式投稿前已在干净环境复跑确认主表与主图一致，并将环境配置、软件与数据版本、复跑命令及受限数据的合规申请方式写入可匿名的复现说明（若目标要求匿名则先完成去身份核查）。
- [ ] 按当前投稿阶段备齐对应交付包（不混用会议答辩与期刊返修模板）：
  - 初投阶段：干净初投 PDF、按需准备的独立附件（如要求时的 Highlights 独立可编辑文件）及匿名补充材料。
  - 会议答辩（Rebuttal）：已记录平台字数/长度限制、截止时间及能否提交新结果或修订稿，备好平台可直接使用的逐点答复（及政策允许时的对应修订稿）。
  - 期刊返修（Major / Minor Revision）：按编辑信清单备齐干净修订稿 PDF、修改说明与逐条回复信 PDF；仅在编辑信或投稿系统明确要求时，额外生成高亮标色对比版（如 `latexdiff` 或按要求标色）。
  - 终稿（Camera-ready）：已关闭匿名开关、补齐作者信息与致谢、确认终稿页限并按出版方要求打包源码与版权/许可文件。
