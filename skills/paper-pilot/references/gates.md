# 阶段门详细退出清单（G0–G8）

每一门的所有退出核验项均须满足，才能在 `status.md` 标为“已通过”并进入下一门。若下游审稿或复核暴露上游漏洞，立即按各门底部的回退规则退回。

---

## G0 选题

进入条件：存在初步研究方向。

必交产出：
- 问题陈述（不超过一页，说明研究对象、现实痛点与预期贡献边界）
- 目标期刊或会议清单（主选 1 个，备选 1–2 个）
- 目标去向格式与政策核验记录（含页限核验起点、匿名政策、指南版本与核对日期，均以当届 CFP 或刊物官方指南为准）
- 里程碑时间线与阶段验收节点
- 初始化的 `status.md`

退出核验项：
- [ ] 研究问题表述具体，而非宽泛领域口号。
- [ ] 已登记目标去向的篇幅核验起点、格式要求、匿名政策（预印本、匿名链接、补充材料与自引规则）及大致截稿时间，并注明指南版本与核对日期（易变条款以当届 CFP 或官方投稿指南为准）。
- [ ] 研究者本人（及必要时的导师）已确认问题陈述与时间线，并记入 `status.md` 决策记录。

---

## G1 文献

进入条件：G0 已通过。

必交产出：
- 论文矩阵 `paper_matrix.csv`（含年份、来源/录用会议期刊、主题分类、代码情况、阅读状态）
- 精读卡片目录 `cards/`
- 领域空白总结（写清现有工作做到哪里、缺什么、缺口有何证据，以及检索截止日与缺失索引）

退出核验项：
- [ ] 采用多源检索并补抓近期预印本，已核查本地索引截断时间并记录检索截止日与缺失索引，无明显漏检。
- [ ] 矩阵覆盖领域经典奠基工作与近期代表工作，无“只收当年预印本”的偏斜。
- [ ] 核心对比论文均已有结构化精读卡（含问题、方法、实验设置、结果、局限）。
- [ ] 能用一段清晰文字概括“现有工作做到哪里、缺什么”，每句判断均有对应卡片支撑；对仅有单篇一手证据支撑的瓶颈，已标注证据强弱与待验证项。

常见回退触发：进入 G2 或 G3 时发现关键基线未检索到，回退 G1 补录矩阵与卡片。

---

## G2 创新点

进入条件：G1 已通过。

必交产出：
- “瓶颈 × 方法”交叉矩阵与候选创新点池
- 针对每个候选的查新报告（含最近 3 个月预印本、最接近工作、关键差异、检索截止日与缺失索引）
- 反方质询记录（逐条列出最尖锐的审稿人质疑与最小可证伪实验设计）
- 三选一提案及作者选定的试跑方案记录
- MVP 探路执行记录与结论 `mvp_report_<id>.md`（含实际运行结果、代码与数据版本、通过线核对与止损决定；预算不足时注明“待验证”及补跑条件）

退出核验项：
- [ ] 每个进入终选的候选创新点均完成查新，写明最接近工作、关键差异、检索截止日与缺失索引，结论限定为“在已检索范围内未发现同机制工作”；改题或久拖未投时已执行增量复查。
- [ ] 每个候选均经过独立反方质询，写明了失败条件和最小可证伪实验（MVP）。
- [ ] 未出现“仅凭文献排序直接锁定方案”的草率决策。
- [ ] 作者亲自拍板选定试跑方案，并记入 `status.md`。
- [ ] 已遵循 `paper-evidence` 提供的真实信号与无泄漏规范开展 G2 探路执行，由 `paper-idea` 记录实际结果、版本、通过线核对与止损决定。
- [ ] 过门分流结论明确：探路通过后方可进入 G3 正式实验；失败则退回候选池切换备选或调整定位；预算不足暂未试跑的项已显式标为“待验证”并记录风险边界与补跑前提，不冒充已验证通过。

常见回退触发：G2 探路失败退回候选池；G3 正式实验推翻核心假设，或查新撞车，回退 G2 调整方案或切换备选。

## G3 证据

进入条件：G2 已通过。

必交产出：
- 实验协议（数据集、按共享来源分组的切分清单与冻结版本、基线清单、计算预算，以及由 `paper-evidence` 冻结的统计分析设计：指标、目标量、分析单元、配对或聚类结构、区间估计与假设检验方法、分母及缺失/失败处理、预先指定的主比较）
- 伦理与数据授权登记（涉及人类参与者或敏感数据时，采集前记录审批或豁免、知情同意范围与数据许可）
- 真实通道复核与诚信检查报告
- 填满的主张-证据对照表（`claim-evidence` 表）

退出核验项：
- [ ] 真实信号核验通过：主实验在真实观测信号下成立，所有由真值派生或加噪的仿真信号均已标记并撤出主结论。
- [ ] 预先冻结切分与去偏通过：冻结切分前先按用户、会话、原始轨迹或近重复簇等共享来源分组，再对组切分并核查交集，保存切分清单与冻结版本；开发集与测试集严格隔离。测试集衍生的规则及其消融均标作探索，任何据此选定的版本须在新留出集复验。仓库内带日期的协议称预先冻结，对外称预注册时已给出可核验登记记录。
- [ ] 构造同构检查通过：测试故障或注入样本不是按方法自身检测谓词造出来的，并包含合理反例。
- [ ] 数据完整性核验通过：拉取与统计脚本无默认 `top_k` 或分页截断，样本总数与预期严格一致。
- [ ] 证据链闭环：发现问题的真实数据源与评测方法的数据源已交汇，避免前半篇讲系统 A 现象、方法只评系统 B。
- [ ] 统计设计冻结与组件贡献厘清：由 `paper-evidence` 按实验设计冻结指标、目标量、分析单元、配对或聚类结构及区间估计方法（如独立配对同步重采样独立单元重算整体指标差值、多轮会话按会话或更高独立层级抽样、独立二项比例方用 Wilson），写清分母、失败或缺失处理及主比较，供 `paper-figure` 与 `paper-story` 直接引用；若另做假设检验，已记录检验方法与多重比较处理并与区间估计分列；在相同候选集与预算下完成消融，确认增益来源可解释。
- [ ] 合规与授权核验通过：涉及人类参与者或敏感数据时，采集前已登记伦理审批或豁免、同意范围和数据许可；涉及外部模型协作处理数据或代码时，已按授权范围共享并记录接收方与留存设置。
- [ ] `claim-evidence` 表已填满，无证据支撑的主张已删除或明确移入局限清单。

常见回退触发：G7 审稿指出存在构造同构、数据泄漏、共享来源混分、消融缺失或方法分量不足，回退 G3 补实验。

## G4 故事

进入条件：G3 已通过。

必交产出：
- 一句话核心主张
- 贡献-证据对照表（含研究问题 RQ 与各条贡献的一一映射）
- 8 页以内的骨架稿 `outline.md`（每节一句话目的、段落提纲、待放图表槽位）与集中未决项清单
- 统一术语与符号表 `glossary_and_symbols.md`（由 `paper-story` 建立并维护，定义论文用名与符号，列出禁止出现的内部代号）

退出核验项：
- [ ] 题目、摘要要点与贡献列表均严格落在 G3 证据边界内，未做的能力（如修复闭环或未实现分支）不进题目与主贡献，统计口径直接引用 G3 冻结设计。
- [ ] RQ 与贡献条目一一对应，读者能清楚看出哪个实验支撑哪条贡献。
- [ ] 骨架稿篇幅控制在 8 页以内，信息主次清晰，没有跨节重复罗列同一组数字。
- [ ] 已按 G4 验收口径完成核验（证据映射、集中未决项清单与作者签字确认，无需提前启动 G7 的全文通读与跨厂商独立盲审），并锁定 `glossary_and_symbols.md` 供 G5 与 G6 共用；后续术语或核心主张变动须走对应回退。

常见回退触发：G6 成稿或 G7 审稿发现叙事失焦、过度声称、定位摇摆或核心术语口径变更，回退 G4 重构骨架并更新 `glossary_and_symbols.md`。

## G5 图

进入条件：G4 已通过。

必交产出：
- 图清单 `figure_plan.md`（每张图先写一句话核心信息）
- 全部正式图表与可复现绘图脚本

退出核验项：
- [ ] 每张图有且仅有一句核心信息，删除信息密度过低的冗余单图或合并为子图。
- [ ] 首图按论文类型选定：实例支撑动机时采用具体实例 teaser（例如带时间线的真实样本演变与多路证据对比），发现型论文可用主结果图，避免塞满文字的方框流程图。
- [ ] 方法架构图只画已实现的路径，清晰标出每路输入与交互，未实现的分支不画成并列。
- [ ] 数据图全部反映最终方法结果，不遗留已弃用版本的旧图；统计指标与区间估计直接引用 G3 冻结设计，术语符号对齐 G4 的 `glossary_and_symbols.md`。
- [ ] 无误导性视觉编码（禁止跨组连线造成配对误读、避免双 y 轴歧义）；全套图遵守统一字体、字号、留白与色义规范（一种颜色只代表一种含义）。
- [ ] 已由未参与绘图者只看图及图注，复述比较对象、单位和核心结论，并与 `figure_plan.md` 核对一致。

常见回退触发：G6 或 G7 发现图表数据与最终方法不一致，或未参与绘图者无法仅凭图和图注准确复述图意，回退 G5 重制。

---

## G6 成稿

进入条件：G5 已通过。

必交产出：
- 按目标期刊或会议模板编写的完整手稿（LaTeX 优先）
- 更新后的集中待补清单（存于 `status.md` 或独立文件）

退出核验项：
- [ ] 直接基于目标期刊/会议官方模板排版（Word 仅作内部讨论稿，不作准投稿版）。
- [ ] 全文扫描确认无内部代号外露（如实验轮次号、脚本名、旧版本名、哈希盐或本地路径）。
- [ ] 主结果表按表注统一标示各列最佳值，正式方法用行标签清晰标识，不混入已弃用变体；数字不跨章节反复堆砌，摘要仅保留 2 至 3 个最关键数字。
- [ ] 源码路径、commit 号等实现细节移至附录或脚注，不塞入正文形式化定义。
- [ ] 所有未完成项集中列于一处，正文中不散落红字标注。
- [ ] 各章节引用清单及术语符号与 G4 锁定的 `glossary_and_symbols.md` 严格一致；分节并行起草的草稿采用分路径输出，由单一主笔按节合稿并在合稿后全篇核对。

常见回退触发：成稿时发现某段论证缺实验支撑，停止补编文字，记入待补清单或回退 G3/G4。

---

## G7 审稿

进入条件：G6 已通过（完整初稿及重大返修/改稿启用本门；G4 骨架稿不走本门）。

职责分工：`paper-review` 负责生成并冻结同版评审记录，`paper-crew` 负责核对交付稿与冻结评审属于同一版本并检视验收清单，`paper-pilot` 依据核对结果决定放行或回退。

必交产出：
- 独立盲审报告 `review_*.md`（明确记录跨厂商独立会话状态，或单厂商隔离预审状态）
- 综合共识、分歧与致命意见逐条清单的元审稿报告 `meta_review.md`
- 交付门验收记录（见 `paper-crew`）

退出核验项：
- [ ] 主控模型或把关人已完整通读全文，而非仅做数字抽查。
- [ ] 独立审稿状态清晰明确：正式门要求至少 2 家不同厂商模型分独立会话隔离执行，互不透题且写稿与审稿分离；若仅能以单厂商分独立会话执行，只能作为预审参考并在状态中标明“正式门待满足”，不得按正式门放行。
- [ ] 审稿意见已区分“表述问题”与“方法缺陷”，并评估每条致命意见的可救性。
- [ ] 已逐条复核所有致命意见，不仅限于多方共识；即便是单方审稿人发现的硬伤，经核实成立同样阻断放行，必须清零、回退补齐，或经作者同意正式降格为局限并同步修改题目与摘要。
- [ ] 若元审稿提出路线分叉（如补实验与改定位的取舍），已由作者拍板并完成相应回退闭环。
- [ ] `paper-review` 已冻结对应版本的评审记录，`paper-crew` 已核对同版材料与记录，交由 `paper-pilot` 决定放行。

常见回退触发：任一经核实的致命意见无法靠文字修改解决，按缺陷类型回退至 G3、G4 或 G5。

---

## G8 投稿/返修

进入条件：G7 已通过（或在初投后进入答辩、返修、终稿阶段）。

本门按当前所处场景在**初投、会议答辩、期刊返修、终稿**四种模式之间切换，按对应模式的必交产出与退出核验项验收。全模式均须满足外发授权与保密要求（审稿意见、私有代码与原始数据仅在授权范围内共享，模型派单前记录授权材料、接收方与留存设置），并在最终提交前经 `paper-crew` 核对同版记录、由 `paper-pilot` 放行且获作者最终确认。

### 模式 A：初投（Initial Submission）

必交产出：
- 通过编译与版式自查的初投包
- 当届投稿规则与附件核对表（注明指南版本、核对日期与核验起点，以当届 CFP 或刊物官方指南为准）
- 参考文献逐条核验记录
- AI 使用披露核查记录
- 干净环境主表主图复跑记录与可匿名的复现说明（环境、版本、命令及受限数据申请方式）

退出核验项：
- [ ] 初投页限、参考文献/附录/Checklist/Impact/Limitations/Ethics 计页与必填规则、匿名政策（预印本、匿名链接、补充材料与自引）均按当届 CFP 或目标刊物官方指南逐项核对，已记录指南版本与核对日期。
- [ ] 刊物附件按具体刊物判定（如 Elsevier 期刊须分别登记 Information Fusion、KBS 等具体刊物对 Highlights、CRediT、利益冲突、数据声明与匿名要求的适用性及上传位置；仅在目标刊物要求提交 Highlights 时，按独立可编辑文件检查 3–5 条、每条 ≤85 字符含空格的口径）。
- [ ] 参考文献逐条核验作者、年份、标题与出处，已将预印本尽量更新为正式发表版本，并保留关键经典奠基工作。
- [ ] 已按目标期刊或会议当届政策核查 AI 使用披露要求并完成对应声明。
- [ ] 已在干净环境中复跑主表和主图，结果与稿件数值一致，并将运行环境、代码与依赖版本、复跑命令及受限数据申请方式写入可匿名的复现说明。
- [ ] 初投包经 `paper-crew` 终版核查、`paper-pilot` 放行并由作者最终确认。

### 模式 B：会议答辩（Rebuttal）

必交产出：
- 平台约束登记单（字符或字数上限、截止时间、是否允许提交新结果或修订稿、贴图与匿名链接规则）
- 可直接粘贴至评审平台的逐点答复（如 `rebuttal.md`）

退出核验项：
- [ ] 动笔前已登记当届评审平台的长度上限、截止时间以及是否允许提交新结果、图表或修订稿，并以当届官方说明为准。
- [ ] 已拆分编号并逐条回应全部审稿意见，不回避硬伤，所引量化结果与实验产物一致，长度严格在平台限制内，且无作者身份泄露。
- [ ] 未违背平台规则提交不允许的修订稿或非匿名材料，也未无故生成平台不接收的标红追踪稿。
- [ ] 审稿意见及答辩草稿未越权外发至不符合保密与留存要求的第三方服务，最终答复经作者确认提交。

### 模式 C：期刊返修（Revision）

必交产出：
- 干净修订稿（Clean Manuscript）
- 逐点回复信 `response.md` 与修改说明（按刊物要求合并或独立提交）
- 标色或追踪修订稿（仅在编辑信或期刊指南明确要求时生成）

退出核验项：
- [ ] 严格按编辑信与期刊返修指南准备干净稿、回复信及修改说明；仅在明确要求时提供标色或追踪修订稿，且标色清晰无错乱。
- [ ] 返修阶段页限、版式、新增声明与参考文献均符合当期指南要求。
- [ ] 逐条回应编辑与审稿人全部意见，每条回复指向干净修订稿中的确切章节、页码、行号或图表号，数值与正文和附录完全一致，不回避硬伤。
- [ ] 涉及补实验或重大改稿时，已先通过 G7 全文通读与独立审稿门；最终返修包经 `paper-crew` 核查、`paper-pilot` 放行并由作者最终确认。

### 模式 D：终稿（Camera-Ready）

必交产出：
- 去匿名终稿包（含编译 PDF、源码与所需附件）
- 终稿合规清单（版权/许可表、最终 AI 使用披露、作者与致谢核验）
