# 多 Agent 任务单模板（brief_template.md）

每次向外部模型或子 agent 派发工作前，按本模板生成独立任务单。未填清的字段标为待补，禁止口头模糊派活。

---

## 1. 任务元信息

- 任务编号：`T-XXX`
- 所属阶段门：`G1 / G2 / G3 / G4 / G5 / G6 / G7 / G8`
- 任务类型：`code / doc / figure / review / scan`
- 复杂度：`低 / 中 / 高`
- 执行者：`指定模型名称`
- 跨厂商复核者：`必须与执行者不同模型家族；若仅能单厂商独立会话隔离执行，注明“单厂商预审（正式门待满足）”`
- 独立会话要求：`审稿与复核任务必须独立会话隔离，禁止共享起草上下文`
- 最大返工轮次：`1 轮（未过则升级或由主控模型接管）`

## 2. 目标与上游锚点

- 一句话目标：说明本次只解决什么问题，不顺带做哪些事。
- 必须严格对齐的上游锚点文件：
  - 骨架稿：`outline.md`（若为写稿任务，注明本任务对应哪一节及该节的一句话目的）
  - 主张-证据表：`claim-evidence` 表路径（含 G3 冻结的统计分析口径）
  - 统一术语与符号表：`glossary_and_symbols.md`（G4 由 `paper-story` 锁定，摘要见第 5 节）
- 禁止事项：未经主控模型与作者同意，不得修改论证主线、不得新增表外主张、不得扩写未实现的模块。

## 3. 输入材料清单

逐条列出允许读取的已授权文件路径、版本号及用途，不给无关历史草稿，防止模型混用过期数字或接触越权材料。

1. `路径 1（版本）`：说明其角色（例如主实验汇总表，仅取最终冻结结果）
2. `路径 2（版本）`：说明其角色

## 4. 输出格式与交付路径

- 输出文件路径：`明确相对路径（若为分节并行写稿，必须指定独立草稿路径，由单一主笔后续按节合稿）`
- 结构要求：明确章节标题层级、段落顺序、字数或行数范围、JSON/CSV 字段名。
- 写作风格约束：中文/英文目标语言、术语保留规则、缺失数据一律写成“待补”不得编造。

## 5. 统一术语与命名表（写作与绘图任务必填，须与 G4 锁定的 glossary_and_symbols.md 一致）

| 概念 | 论文正式用名与符号 | 禁止出现的内部代号或旧称 |
|---|---|---|
| 待补 | 待补 | 例如实验轮次号、脚本名、临时版本号 |

## 6. 边界、外发授权与安全规则

### 派单前外发授权与接收方登记（外派模型前必填，未核实填待补）

- 授权共享材料清单与脱敏状态：`仅限第 3 节列出的已授权文件；审稿意见、私有代码与原始数据仅按授权范围与刊物/会议保密要求共享，未经授权不得外发`
- 接收方：`模型提供方、具体模型版本及调用平台/端点`
- 服务留存与训练设置：`零留存 / 关闭用于训练 / 企业协议状态（未确认填待补）`

### 人类参与者与敏感数据合规登记（涉及时采集与派单前必填，不涉及填“不适用”）

- 伦理审批或豁免记录：`审批机构与编号，或豁免依据`
- 知情同意范围：`允许的研究用途、共享边界与二次使用限制`
- 数据许可条款：`许可协议名称及禁止外发、再分发或商用约束`

### 执行安全红线

- 不修改允许范围之外的任何文件。
- 不执行未授权的联网、提交或删除操作。
- 不将未获授权的审稿意见、私有代码或受限原始数据写入外部提示词、日志或公开链接。
- 不编造任何文献、DOI、实验数值或统计检验结果。
- 遇到输入材料自相矛盾时，暂停臆测，在输出末尾“待确认事项”中列出冲突位置。

## 7. 公开自查标准（执行者提交前逐条自检）

- [ ] 输出路径与格式完全符合第 4 节要求。
- [ ] 每个数字均可追溯到第 3 节提供的输入材料。
- [ ] 全文扫描未出现第 5 节黑名单中的内部代号，术语与 `glossary_and_symbols.md` 一致。
- [ ] 无未完成项散落正文的红字占位，所有待补项集中列在指定位置。
- [ ] 全程未超出第 6 节登记的授权范围使用或外发敏感数据、私有代码与审稿意见。

## 8. 主控模型隐藏验收项（不发给执行者，仅主控把关使用）

- 隐藏测试或抽查方案：例如边界输入测试、样本总数无截断核对、与上下游章节的衔接一致性抽查、交付文件与冻结版本一致性核对。
- 跨厂商复核重点：提示复核模型在独立会话中重点排查逻辑漏洞、构造同构、过度声称或隐蔽重复，并核实其跨厂商与独立会话状态。
